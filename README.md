# Python Adventure Game

A terminal-based beginner Python project that practices user input, conditionals, nested branches, and formatted output.

## Run

Requires Python 3 and no external packages.

```bash
git clone https://github.com/bajily/Python-game.git
cd Python-game
python Game.py
```
ز
Enter a name, a numeric age, and the numbered choices prompted by the program. The game uses a fictional age gate of 18 and offers paths and boxes with fixed outcomes.

## What this project demonstrates

- Interactive terminal input with `input()`
- Integer conversion and conditional logic
- Nested story choices and formatted strings
- Unicode terminal output

## Current limitations

Non-numeric input raises an exception. Outcomes are fixed, and the script runs immediately when imported. This is an early learning project; future improvements could add input validation, reusable functions, replay, and automated tests.
